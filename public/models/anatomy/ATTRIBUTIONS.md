# OSTM™ Interactive Human Anatomy Atlas — Open Source Asset Attributions

This document provides complete provenance, license notices, and academic citations for all authentic 3D human anatomical models utilized within the **OSTM™ Interactive Human Anatomy Atlas**.

---

## 1. Licensing Principles
- All anatomical models bundled in this application are distributed under open-access licenses that explicitly grant redistribution, derivative works, and interactive rendering (primarily **Creative Commons Attribution 4.0 International - CC BY 4.0** or **Creative Commons Public Domain Dedication - CC0**).
- No unvetted Non-Commercial (NC) third-party components or restricted proprietary meshes are utilized.
- All models are provided for **medical education, anatomical reference, and interactive learning purposes only** and are not diagnostic medical devices.

---

## 2. Asset Provenance & Attribution Register

### Digestive System
- **Stomach Model (`stomach.glb`)**
  - **Creator / Source**: National Institutes of Health (NIH) / National Library of Medicine (NLM)
  - **Repository**: [NIH 3D Model Repository](https://3d.nih.gov)
  - **Source ID**: `3DPX-016666`
  - **License**: CC BY 4.0 ([https://creativecommons.org/licenses/by/4.0/](https://creativecommons.org/licenses/by/4.0/))
  - **Provenance**: Derived from human anatomical cross-sectional reference datasets and clinical modeling (`anatomically-modeled`).
  - **Modifications**: Converted to binary GLB, normalized pivot coordinates, tagged anatomical sub-regions (fundus, body, pyloric antrum, lesser/greater curvature).
  - **Attribution**: *Stomach Anatomy Model via NIH 3D / CC BY 4.0.*

- **Liver & Gallbladder (`liver_gallbladder.glb`)**
  - **Creator / Source**: HuBMAP Consortium / Human Reference Atlas (HRA)
  - **Repository**: [Human Reference Atlas 3D Reference Object Library](https://humanatlas.io/3d-reference-library)
  - **Source ID**: `HRA-LIVER-VH-M-001`
  - **License**: CC BY 4.0
  - **Provenance**: Visible Human Male dataset registered to the CCF 3D spatial reference library (`imaging-derived`).
  - **Attribution**: *HuBMAP Consortium CCF 3D Reference Object Library (CC BY 4.0).*
