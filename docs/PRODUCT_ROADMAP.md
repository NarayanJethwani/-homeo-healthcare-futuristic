# Product Roadmap

This document outlines the strategic milestones and features planned for the Unified Clinical OS platform.

## Sprints & Milestones Roadmap

### Version 1.0 — Knowledge Platform Foundation
- **Goals**: Consolidate clinician workspace into a single pane of glass, construct the core typescript models, and launch the primary Materia Medica database.
- **Status**: Completed (2026-07-03)

### Version 2.0 — Clinical Authority Platform
- **Goals**: Scale Knowledge Base database, implement immersive `KnowledgeGraphExplorer`, configure rate-limiting security shields, and establish multi-provider fallback chains (Gemini/DeepSeek).
- **Status**: Completed (2026-07-08)

### Version 2.1 — Editorial Excellence
- **Goals**: Establish administrative editorial cockpit, cornerstone tracker, and Search Console/Analytics adapters. Prepare AI metadata schemas and Clinical OS integration link resolvers.
- **Status**: Completed (2026-07-09)

### Version 2.2 — AI Knowledge Layer
- **Goals**: Implement semantic search vector retrieval pipelines, automate RAG traversals, index vector embeddings, and introduce automated AI-assisted writing review suggestions.
- **Status**: In progress (Q3 2026). RAG security, provider observability, deterministic verification, and the governed local embedding-cache foundation are complete. Source-version eligibility, approved-corpus activation, and editorial source integration remain.

### Version 2.3 — Clinical OS Integration
- **Goals**: Enable active cross-referencing between patient records and the Knowledge base, displaying remedy indicators directly inside the Treatment Planner and Lab interpretation panels.
- **Status**: Planned (Q4 2026)

### Version 3.0 — Intelligent Homeopathy Ecosystem
- **Goals**: Deploy the unified clinical decision engine globally, integrating patient timeline monitoring, calibration suites, and direct multi-agent clinical OS capabilities.
- **Status**: Planned (2027)
