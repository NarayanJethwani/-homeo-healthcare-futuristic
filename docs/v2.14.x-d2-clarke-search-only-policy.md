# Clarke 1904 Clinical Repertory Search-Only Publication Policy

This document defines the search-only Classical Source Policy for John Henry Clarke’s 1904 Clinical Repertory.

## Rationale for Search-Only Classification

Clarke’s original 1904 print edition used three levels of grading typography:
* **ORDINARY TYPE**: Standard clinical indication (weight 1)
* *Italics*: Stronger clinical indication (weight 2)
* **CAPITALS**: Keynote or highly verified indication (weight 3/4)

Because the available plain text OCR files discarded font styling (leaving all text plain), the original grading weight is unrecoverable. 

Assaging a uniform fallback grade of `1` is rejected because it:
1. Distorts multi-source repertorization scoring.
2. Misleads practitioners into believing all listed remedies have equal clinical verification.
3. Unfairly biases scores toward larger modern repertories.

Therefore, Clarke is restricted to **search-only** status until a font-recovering parser is approved.

## Scope of Search-Only Operations

The following operations are permitted for the Clarke source:
* Exact-text and normalized keyword search on rubrics and subrubrics.
* Source-based and section-based filtering.
* Display of original remedy abbreviations as printed.
* Display of mapped approved canonical remedy names.
* Citations linking to physical scan and printed page numbers.

## Scoring Exclusions

* Clarke rubrics are excluded from contributing to remedy totals, coverage ratios, balanced scores, and confidence scores.
* When a user selects a Clarke rubric in an analysis session, the rubric is moved to the `nonScoringRubrics` array with the reason `source-search-only`.
* The API returns a structured warning: `CLARKE_SCORING_DISABLED_UNVERIFIED_GRADES` to notify the practitioner.
