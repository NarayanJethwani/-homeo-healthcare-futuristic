## Runtime Safety Boundary

- Both EMR feature flags default to `false`.
- The page returns not-found while reconciliation is disabled.
- The API returns not-found while reconciliation is disabled.
- Only signed administrator sessions may access the enabled endpoint.
- Doctors receive forbidden.
- The repository selects identity metadata only.
- Interactive reads are capped at 5,000 documents per collection.
- Truncated reports visibly prohibit migration decisions.
- No merge, edit, delete, or migration-write action exists.
