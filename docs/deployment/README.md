# Deployment Documentation

This folder contains deployment, rollout, rollback, and production risk documents.

## Contents

- `PRE_DEPLOYMENT_SHADOW_MODE_CHECK.md` - pre-deployment shadow mode verification.
- `PRODUCTION_DEPLOYMENT_REPORT.md` - production deployment summary and health checks.
- `RELEASE_CHECKLIST_V2_SHADOW.md` - release checklist for V2 shadow mode.
- `ROLLBACK_PLAYBOOK.md` - rollback procedures and stop conditions.
- `SAFE_ROLLOUT_STRATEGY.md` - staged rollout strategy.
- `V2_DEPLOYMENT_RISK_REVIEW.md` - V2 deployment risk assessment.
- `V2_INTEGRATED_WORKSPACE_DEPLOYMENT_REPORT.md` - integrated workspace deployment report.
- `V2_LIVE_DEPLOYMENT_REPORT.md` - V2 live deployment report.
