# Clarke 1904 Clinical Repertory RAG Context & Retrieval Policy

This document defines the RAG retrieval and metadata disclosure guidelines for John Henry Clarke’s 1904 Clinical Repertory.

## RAG Formatting Rules

When Clarke 1904 rubrics are retrieved for LLM context (e.g. in the Clinical OS consult-ai assistant), the RAG generator must format each snippet with explicit metadata disclosures:

```text
Source: John Henry Clarke's Clinical Repertory (1904)
Section: [Clinical Section Path]
Rubric: [Rubric Wording]
Original Remedy Abbreviations: [Raw remedy tokens, e.g., Phel., Pie.]
Mapping Status: [approved-mapped / unresolved]
Warning: Scoring Disabled. Original print grades (ordinary/italics/caps) are unverified in this digital edition. Do not use for numerical repertorization scores.
```

## Retrieval Policies

1. **Safety Disclosures**: All RAG answers derived from Clarke must include a user-facing footnote explaining that the source is search-only due to unverified grades.
2. **Local Confidence**: If local RAG confidence threshold is $\ge 90\%$, a direct answer is allowed but must retain the search-only footnote.
3. **Medical Safety Filters**: Queries containing clinical red flags (e.g., emergency symptoms) must trigger immediate crisis escalation filters and bypass Clarke search lookup completely.
